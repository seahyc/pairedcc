Items (mark each addressed with the PR link):

1. [ ] Hard to use; the first minute has no obvious thing to do.
2. [ ] Not built on the project's principles ("How humans think intuitively" in the working spec).
       The pass had anchored on Jakob Nielsen's heuristics instead.
3. [x] Too noisy: too much chrome and too much on the first board. Addressed by [#21](https://github.com/seahyc/pairedcc/pull/21): the first board holds three things and the panels are behind one menu (checked by script; for the second playtest to judge).
4. [ ] Too flexible and too open-ended: a blank tool rather than an opinionated loop.
5. [x] Typed text flows out of its container instead of wrapping. Addressed by [#21](https://github.com/seahyc/pairedcc/pull/21): cards, plain text, comments and a 300-word paste all wrap (checked by script).
6. [x] No visible way to make the agent respond. Addressed by [#21](https://github.com/seahyc/pairedcc/pull/21): Ask on the selection and in the toolbar, with waiting, working, answered or failed shown on the ask (checked by script with a stand-in for the model).
7. [ ] Bring in the relevant Solveit principles.

Items 1, 2, 4 and 7 are what [#21](https://github.com/seahyc/pairedcc/pull/21) sets out to do; whether it does is for the second playtest, so they stay open here.

A rework addressing these for a second playtest is on branch `yc/calm-canvas`. It was merged into `claude/sprint-int` on 26 Nov as #21. Do not duplicate it:
wait for its PR, then build on it.
