# Paired agent guide

Preserve the existing document editor, server, SDK, CLI and document MCP server. The thinking canvas lives in `packages/canvas`; its working specification is `docs/canvas/working-spec.md`. Canvas code was moved from Picabird, which remains a separate shopping/data project.

The canvas answers to `docs/canvas/principles.md` (how people think, what produces understanding, Solveit); `docs/canvas/usability-heuristics.md` is a secondary checklist. Read `packages/canvas/README.md` and `AGENT_API.md` for local setup, current capabilities and limitations. Browser storage keys retain the Picabird names solely for local document compatibility. Runtime branding, MCP environment variables and transport events use Paired.

The canvas is a prototype; boards are still saved in each browser. Never expose the Vite development relay as a hosted backend. Hosted agent access is an authenticated relay in the server: MCP clients sign in through OAuth at `/oauth/*` (paired.cc accounts), call `/mcp`, and commands reach the user's own signed-in canvas tab over `/canvas-relay` (`packages/server/src/canvas`, `packages/server/src/oauth`). It only forwards commands; durable server-side boards are the next step. The same relay has a resident-agent channel (`packages/server/src/canvas/resident.ts`): off unless `CANVAS_RESIDENT_SECRET` is set, and it only ever hands over asks from accounts in `CANVAS_RESIDENT_ALLOW`, because the agent behind it spends its owner's model subscription. Keep both properties. The public canvas lives at `/canvas/` (the domain landing page), document links remain available, and agents read `/agent-setup.md` to connect themselves. Tool definitions live in `packages/canvas/tools/tool-defs.ts`; after changing them run `pnpm --filter @pairedcc/canvas manifest` to regenerate the hosted manifest.

Use the pnpm workspace scripts for canvas checks. No global MCP registration was changed. The macOS local services are `com.paired.canvas.dev` (dev server) and `com.paired.canvas.agent` (the resident agent that answers asks with the local Claude Code CLI).
